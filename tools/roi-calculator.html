Return on investment calculator

ROI is a simple way to compare the return generated by an investment with the amount invested. Enter the original cost and the final value or revenue received to calculate both net profit and ROI percentage.

ROI formula

Net return = Final value − Investment
ROI % = Net return ÷ Investment × 100

Example

If an investment costs $10,000 and produces a final value of $13,500, the net return is $3,500 and ROI is 35%.

ROI does not measure time

A 20% ROI earned in six months is different from the same ROI earned over five years. This simple calculator does not annualize returns, model cash-flow timing or adjust for inflation, risk, tax or financing costs.

Common questions

Can ROI be negative?

Yes. If the final value is below the original investment, the net return and ROI are negative.

Can I use revenue instead of final value?

Only if revenue is the appropriate return measure for your analysis. For a business project, consider whether operating costs should be deducted before interpreting ROI.
