Project cost estimator

Use this calculator to build a simple planning budget from labor, materials or purchases, software or external services and a separate contingency allowance.

Formula

Labor cost = Labor hours × Blended hourly cost
Base project cost = Labor + Materials + Software/Services
Contingency = Base cost × Contingency %
Planning budget = Base cost + Contingency

Example

At 120 labor hours and $65 per hour, labor cost is $7,800. Adding $3,500 of materials and $1,200 of software or services gives a $12,500 base cost. A 12% contingency adds $1,500, for a $14,000 planning budget.

What contingency means

Contingency is a planning reserve for uncertainty. It should not be confused with profit, tax or an automatic spending allowance. The appropriate percentage depends on scope clarity and project risk.

Common questions

What is a blended hourly cost?

It is an average cost per labor hour across the people working on the project. It can include wages and other internal cost components if your costing method requires them.

Does this calculate selling price?

No. It estimates project cost. Add profit, tax or commercial markup separately if needed.
